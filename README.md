# Task 5: Host a Static Website with GitHub Pages

## Objective

Create and publish a responsive static portfolio website using GitHub Pages, without a backend.

## Technologies

HTML5, CSS3, Git, GitHub, and GitHub Pages.

## Website sections

The portfolio includes a hero section, About, Technical Skills, Projects & Practice, and Contact.

## Deploy with GitHub Pages

1. Push `index.html`, `style.css`, and this README to the `main` branch of the repository.
2. In the repository on GitHub, open **Settings** → **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/(root)` folder, then click **Save**.
5. Wait for GitHub Pages to publish the site. The published URL will be shown in the Pages settings.
